### ?? DocuMind-AI
> **RAG-powered Document Intelligence System**

Upload PDFs, DOCX, or TXT files and ask natural-language questions. The system chunks documents, generates embeddings with `sentence-transformers/all-MiniLM-L6-v2`, indexes them in FAISS for millisecond-level vector search, and routes queries through a Groq LLM (LLaMA-3.3-70B) to return accurate, cited answers.

**Pipeline:** `Upload ? Extract ? Chunk ? Embed ? FAISS ? LLM ? Answer`
